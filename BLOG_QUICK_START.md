# Blog Post Page - Quick Start Guide

## 🚀 Quick Navigation

**Blog Post Page**: `/blogs/post`  
**Blog List Page**: `/blogs`

---

## 📝 How to Post a Blog

### Step 1: Access the Blog Post Page
- Navigate to `/blogs/post` or click "Post a Blog" button from the blogs list

### Step 2: Add Featured Image (Optional)
- **Drag & Drop**: Drag an image file into the designated area
- **Or Click**: Click "Click to browse" to select from your device
- **Supported Formats**: JPG, PNG, WebP (max 5MB)
- **Replace Image**: Click the ⟳ button to swap the image
- **Remove Image**: Click the ✕ button to remove it

### Step 3: Fill in Blog Details
**Title** ⭐ Required
- Maximum 100 characters
- Be descriptive and catchy
- Example: "Top 10 Corporate Gifting Trends for 2024"

**Author Name** (Optional)
- Your name or company name
- Defaults to "Anonymous" if left empty
- Maximum 50 characters

**Category** (Optional)
- Choose from 9 categories
- Defaults to "General"
- Options:
  - Branding
  - Marketing
  - Corporate Gifting
  - Design Tips
  - Industry News
  - Trends
  - Sustainability
  - Tips & Tricks
  - Other

### Step 4: Write Summary/Excerpt
**Summary** (Optional)
- 150-300 words recommended
- Appears on blog list page
- Encourages readers to click "Read More"
- If empty, defaults to the blog title
- Maximum 500 characters

### Step 5: Write Blog Content ⭐ Required
**Content Requirements**:
- Minimum 10 words
- No maximum limit
- Use blank lines to separate paragraphs
- Plain text format (markdown-style with line breaks)

**Tips for Better Content**:
- Start with an engaging introduction
- Use clear headings (even in plain text)
- Break into short paragraphs
- Use line breaks for readability
- End with a call-to-action

### Step 6: Review & Publish
- **Check Validation**: Ensure required fields are filled (title and content)
- **Publish Button**: Becomes active when form is valid
- **Cancel Button**: Discards all changes (confirmation required if you have content)

---

## ✅ Form Validation Checklist

Before clicking "Publish Blog", ensure:

- ☑️ Blog Title is filled (required)
- ☑️ Blog Content has at least 10 words (required)
- ☑️ Featured Image is JPG, PNG, or WebP (if uploading)
- ☑️ Featured Image is under 5MB (if uploading)
- ☑️ Author Name is filled (recommended for credibility)
- ☑️ Category is selected (recommended for better organization)
- ☑️ Summary is compelling (recommended for higher click-through)

## 🖼️ Image Best Practices

### Recommended Image Specs
- **Size**: 1200 × 675 pixels
- **Format**: JPG or PNG (upload), converts to WebP
- **File Size**: 200-500KB recommended
- **Aspect Ratio**: 16:9 (widescreen format)

### Image Tips
1. Use high-quality images (no pixelated/blurry photos)
2. Make sure image is relevant to content
3. Avoid images with too much text
4. Ensure good contrast for visibility
5. Consider mobile viewing

### Category-Specific Image Ideas
- **Branding**: Logo variations, brand evolution
- **Marketing**: Campaign visuals, social media graphics
- **Corporate Gifting**: Product images, packaging
- **Design Tips**: Design examples, before/after
- **Industry News**: News graphics, infographics
- **Trends**: Trend visualization, statistics
- **Sustainability**: Green initiatives, eco-materials
- **Tips & Tricks**: Step-by-step guides, tutorial images

## 💾 Saving & Navigation

### Auto-Save
⚠️ **Note**: Your form is NOT auto-saved. If you close the page, your content will be lost.

### Save Progress
If you need to save your progress:
1. Copy all your text content
2. Save to a document/notepad
3. Return and paste back in

### Safe Navigation
- **Cancel Button**: Use to go back to blogs list
- **Confirmation Dialog**: You'll be asked to confirm if you have unsaved changes
- **Browser Back Button**: Same as Cancel button

## ❓ Frequently Asked Questions

### Q: Can I edit my blog after publishing?
**A**: Currently, no. Please ensure all content is correct before publishing. (Edit feature coming soon)

### Q: What if I forget the author name?
**A**: It will automatically be set to "Anonymous"

### Q: Can I publish without an image?
**A**: Yes, a default image will be used on the blog list

### Q: What's the maximum blog length?
**A**: No maximum! Write as much as you want

### Q: Can I use rich text or markdown?
**A**: Currently plain text only. Use line breaks for formatting.

### Q: How long does publishing take?
**A**: Usually 1-2 seconds, then redirects to blog list

### Q: Can I delete my blog?
**A**: Contact admin for blog management/deletion

### Q: What if the image doesn't appear?
**A**: Ensure file is under 5MB and valid format (JPG/PNG/WebP)

### Q: Can I see my published blog immediately?
**A**: Yes, it appears in the blog list after publish (may require page refresh)

## 🛠️ Troubleshooting

### Problem: "Blog published successfully" but can't see blog
**Solution**:
1. Refresh the blogs list page
2. Wait a few seconds
3. Check if blog appears
4. Check browser console for errors

### Problem: Can't upload image
**Solution**:
1. Check file size (must be under 5MB)
2. Check file format (must be JPG, PNG, or WebP)
3. Check file integrity (try another image)
4. Check browser permissions for file access

### Problem: Form keeps showing errors
**Solution**:
1. Ensure title is filled
2. Ensure content has at least 10 words
3. Check all required fields are completed
4. Refresh page if errors persist

### Problem: Can't go back to blogs list
**Solution**:
1. If Cancel confirmation appears, click "OK"
2. If stuck, use browser back button
3. Or navigate directly to `/blogs`

### Problem: Typed content disappeared
**Solution**:
1. Unfortunately, auto-save is not implemented
2. Copy content before navigating away
3. Or refresh page without navigating away

## 🎓 Writing Tips for Better Engagement

### Title Best Practices
- Use action words: "Learn", "Discover", "Master"
- Include numbers: "5 Ways to...", "Top 10..."
- Make it specific: "How to Choose Corporate Gifts" (not "Corporate Gifts")
- Keep under 70 characters for search visibility

### Summary Best Practices
- Hook the reader in first sentence
- Highlight key value proposition
- Use 150-250 words
- Include relevant keywords
- End with a question or teaser

### Content Best Practices
- Start with clear introduction
- Use short paragraphs (2-3 sentences)
- Break ideas into logical sections
- Use examples and case studies
- End with clear conclusion
- Proofread before publishing
