## 📋 Common Tasks

### How to Post a Blog
1. Go to `/blogs/post`
2. Add featured image (optional)
3. Fill in title (required)
4. Fill in content (required, 10+ words)
5. Add author (optional)
6. Select category (optional)
7. Write summary (optional)
8. Click "Publish Blog"

### How to Upload an Image
1. Click upload area or drag image
2. Image appears in preview
3. Click ⟳ to replace or ✕ to remove
4. Supported: JPG, PNG, WebP
5. Max size: 5MB

### How to Find Documentation
1. Check this index for topic
2. Click on recommended document
3. Use Ctrl+F to search within document
4. Refer back to this index for quick links
